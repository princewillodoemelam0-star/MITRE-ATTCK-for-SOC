# MITRE-ATTCK-for-SOC
MITRE ATT&amp;CK mastery for SOC Analysts | Mapping real alerts → techniques (T1110, T1059+), threat hunting, detection engineering &amp; incident reporting. Ready for SOC L1/L2 or Detection Engineer roles.


Currently leveling up as a SOC Analyst through the MITRE ATT&CK Framework.
I’m actively studying how real-world attacks map to the ATT&CK knowledge base — the global standard for understanding adversary tactics, techniques, and procedures (TTPs).
Key areas I’m focusing on:
Mapping SIEM alerts (e.g. Wazuh failed SSH logins) → MITRE T1110 – Brute Force
Differentiating Tactics, Techniques, and Procedures
Threat hunting starting from techniques like T1059 (Command & Script Execution)
Writing professional incident reports with MITRE mappings
Identifying detection gaps by comparing what we can detect vs. what attackers actually do
Using the ATT&CK Navigator and exploring both Enterprise and ICS matrices
MITRE ATT&CK is mandatory knowledge for moving from SOC Level 1 to Level 2, and I’m treating it as such.
